# [ARDUINO]Button + LED

## About

The LED lights up when the button is pressed.

## How to Use

First, download the Arduino IDE if you don't have it. Then, go to the file called "Button_LED.ino" and copy and paste that into the Arduino IDE. The wiring is listed below with a diagram.

## Building

### Parts Needed

- Any Arduino board.
- A breadboard.
- A button
- An LED(any color).
- A 10K ohm resistor.
- A 220 ohm resistor.
- 7 wires.
